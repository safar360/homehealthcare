# User Flow for Phase 1

## Patient Flow
1. Patient opens the app.
2. Patient logs in or signs up.
3. Patient lands on the dashboard.
4. Patient views care plan and upcoming visits.
5. Patient sees nurse/assistant status and ETA.
6. Patient taps "Contact support" if needed.

## Staff Flow
1. Staff logs in.
2. Staff views assigned visits.
3. Staff updates arrival or completion status.
4. Staff submits visit progress.

## Admin Flow
1. Admin logs in.
2. Admin views schedules and patients.
3. Admin assigns staff to visits.
4. Admin monitors progress and updates records.
